# Bookish

Mobile-first community for book lovers: **sell** and **buy** pre-loved books, and share **reviews**.

## What’s in this repo (design phase)

| Folder | Contents |
|--------|----------|
| [`design/`](design/) | UX research, product definition, IA, wireframes, visual direction, screen inventory |
| [`prototype/`](prototype/) | Clickable HTML/CSS/JS mobile prototype |

## Review the design

1. Read [`design/06-screen-inventory.md`](design/06-screen-inventory.md) (approval checklist).
2. Open [`prototype/index.html`](prototype/index.html) in a browser and click through Sell, Browse/Buy, and Review.
