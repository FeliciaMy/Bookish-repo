# Bookish prototype

Interactive **mobile-first** design prototype for Bookish. No build step.

## Open it

1. Open `index.html` in a browser (double-click, or drag into Chrome/Safari).
2. Or from the project root:

```bash
open prototype/index.html
# or: python3 -m http.server 8080 --directory prototype
```

Use the **phone frame** in the center. Studio links above the phone jump to major flows.

## Flows to click through

| Flow | Start |
|------|--------|
| Onboarding | Welcome → Get started → Profile setup → Home |
| Browse / buy | Explore → sale → Comment / Buy → Arrange purchase |
| Sell | Sell tab → steps 1–5 → Publish |
| Community review | FAB ✎ on Home → Write review → Publish → Review detail (like / comment) |
| Profile | Profile tab → Listings / Reviews / Saved · Settings |
